## 📖 محاور العرض (Presentation Outline)
1. **Definition**: تعريف المضخم ودوره في رفع سعة الإشارة.
2. **Working Principle**: مبدأ العمل وسريان الإشارة `Input → Amplifier → Output`.
3. **Main Components**: المكونات الرئيسية الأربعة (إشارة الدخل، عنصر التكبير، مصدر التغذية، إشارة الخرج).
4. **Types of Amplifiers**: الأنواع الأربعة (مضخم الجهد، التيار، القدرة، والتشغيلي Op-Amp).
5. **Applications**: التطبيقات العملية (أنظمة الصوت، الأجهزة الطبية ECG، الراديو والاتصالات، وأجهزة القياس).
6. **Voltage Gain**: حساب كسب الجهد ومعادلة $A_v = \frac{V_{out}}{V_{in}}$.
7. **Conclusion**: الخلاصة وأهمية المضخمات في عالم الإلكترونيات الحديثة.
